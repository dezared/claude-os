# Plans

One file per feature, named `<date>-<slug>.md`, written by `/feature` from an approved spec in `{{docsDir}}/specs/`.

A plan is a list of small tasks in order. Each task names the exact files it touches, the test that proves it and its done-check, with a checkbox (`- [ ]`) ticked when its commit lands. A plan does not repeat the spec: it links it and says how to build it.
