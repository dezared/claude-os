---
Install Obsidian on the user's Windows machine, from outside WSL if needed. Use the official source only: `winget install Obsidian.Obsidian`, or the installer from https://obsidian.md/download. Show the exact command and wait for approval before running it.

Then tell them how to open this folder as a vault in Obsidian: `{vault}`. Do not change anything inside the vault.
