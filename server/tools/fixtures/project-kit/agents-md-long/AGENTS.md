# Agent guide

This repository holds a command line tool that converts CSV exports into reports.

## Setup

- Install Python 3.12 and run `pip install -r requirements-dev.txt`.
- Copy `.env.example` to `.env` and fill in the report bucket name.

## Commands

- Tests: `pytest -q`
- Lint: `ruff check .`
- Format: `ruff format .`
